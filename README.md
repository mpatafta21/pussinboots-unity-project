# 🐱 Puss in Boots – 2D platformer (Unity projekt)

Ovaj projekt izrađen je u sklopu kolegija **Razvoj računalnih igara** na *Sveučilištu u Zagrebu, Fakultetu organizacije i informatike*.  
Radi se o 2D platformer igri pod nazivom **Puss in Boots**, razvijenoj pomoću **Unity Enginea** i **C# programskog jezika**.

---

## 🎯 **Cilj projekta**
Cilj projekta bio je razviti potpunu 2D videoigru koristeći Unity okruženje, demonstrirajući razumijevanje:
- rada s fizičkim sustavom Unityja (Physics2D),  
- izrade animacija i upravljanja događajima,  
- primjene skripti u C# za kontrolu igrača i objekata,  
- dizajna razina i implementacije korisničkog sučelja.

---

## 🧠 **Opis igre**
**Puss in Boots** je 2D platformer igra u kojoj igrač preuzima ulogu mačka koji prolazi kroz razne prepreke, skuplja bodove i izbjegava neprijatelje.  
Cilj igre je proći sve razine bez gubitka života, koristeći kombinaciju refleksa i strategije.  
Projekt obuhvaća:
- animacije lika u hodanju, skakanju i napadu,  
- kolizije s neprijateljima i objektima,  
- zvučne efekte i pozadinsku glazbu,  
- jednostavno korisničko sučelje (UI) s brojačem bodova i života.

---

## 🧩 **Korištene tehnologije**
- **Game engine:** Unity 2022.x  
- **Programski jezik:** C#  
- **Grafika:** 2D sprite-ovi i tilemap sustav  
- **Zvuk:** Unity AudioSource sustav  
- **Platforma:** Windows / WebGL build  
- **Verzioniranje:** Git + GitHub  

---

## 🕹️ **Upute za pokretanje**
1. Klonirajte ili preuzmite repozitorij.  
2. Otvorite mapu projekta u **Unity Hubu** (verzija 2022.x ili novija).  
3. Pokrenite scenu `MainScene.unity`.  
4. Pokrenite igru klikom na **Play ▶️** unutar Unity editora.  
5. Igru je moguće eksportirati u `.exe` (Windows) ili WebGL format.
